# Misión: Zaid - Gimnasio Cerebral

Este proyecto es una aplicación web diseñada como un "Gimnasio Cerebral" para Zaid, enfocada en el desarrollo de habilidades cognitivas, motricidad fina y ciudadanía digital.

## Estructura del Proyecto

*   **Plan Semanal Base**: Cronograma cíclico de actividades diarias.
*   **Reto Analógico (30 días)**: Actividades físicas sin pantallas (motricidad, escritura).
*   **Reto Digital (30 días)**: Entrenamiento en tablet/PC (destreza, lógica).
*   **Banco de Ideas**: Repositorio de variantes para evitar la repetición.

## Tecnologías

*   HTML5
*   Tailwind CSS (vía CDN)
*   Font Awesome (Íconos)
*   Javascript (Lógica de estado y renderizado)
*   Canvas Confetti (Efectos visuales)

## Despliegue (Hosting)

Este proyecto es un sitio estático (HTML/JS/CSS puros).

### Opción Recomendada: Cloudflare Pages
1.  Conecta este repositorio de GitHub a Cloudflare Pages.
2.  Configuración de build:
    *   **Build command**: (Dejar vacío o `npm run build` si añades package.json)
    *   **Output directory**: `/` (Raíz) o dejar vacío.
3.  ¡Listo! Cloudflare detectará automáticamente el `index.html`.

### Opción Alternativa: GitHub Pages
1.  Ve a `Settings` > `Pages` en este repositorio.
2.  Selecciona la rama `main` y la carpeta `/root`.
3.  Guarda los cambios.

## Ejecución Local
Simplemente abre el archivo `index.html` en tu navegador favorito.
